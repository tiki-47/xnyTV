# TV 集中管理系统 — 内网部署说明

## 系统架构

```
内网服务器 (Windows 10)
├── MySQL 8.0          ← 数据库
└── tvservice.jar      ← 管理服务 (端口 8080)

终端设备
├── 安卓TV / 小主机+传统TV  ← tvclient APK
└── PC小主机              ← xnykiosk 安装包
```

---

## 一、服务端部署（Windows 10 服务器）

### 1. 安装 JDK 17

下载地址（选 Windows x64 Installer）：
https://adoptium.net/temurin/releases/?version=17

安装到默认路径：`C:\Program Files\Java\jdk-17`

### 2. 安装 MySQL 8.0

下载地址（MySQL Installer）：
https://dev.mysql.com/downloads/installer/

安装时：
- 选择 MySQL Server 8.0
- 设置并记住自己的 MySQL 密码，源码不包含默认数据库密码
- 端口保持 3306

### 3. 初始化数据库

双击运行：`deploy\2_setup_database.bat`

按提示输入 MySQL 密码，自动创建数据库 `tv_management`。

### 4. 配置服务端

在启动服务的 PowerShell 7 终端设置数据库环境变量：
```powershell
$env:SPRING_DATASOURCE_USERNAME = "root"
$env:SPRING_DATASOURCE_PASSWORD = Read-Host "MySQL 密码" -MaskInput
```

如果 MySQL 不在同一台机器，可同时设置完整 JDBC URL：
```powershell
$env:SPRING_DATASOURCE_URL = "jdbc:mysql://数据库主机:3306/tv_management"
```

请在同一终端运行启动脚本，或通过系统设置为服务运行账号配置这些环境变量后重启服务。Windows PowerShell 5.1 不支持 `-MaskInput`，可使用 PowerShell 7 或系统环境变量设置。`.env` 不会被自动加载。

### 5. 编译服务端

双击运行：`deploy\1_build_server.bat`

### 6-A. 直接启动（测试/临时使用）

双击运行：`deploy\3_start_server.bat`

窗口不要关闭，关闭即停止服务。

### 6-B. 安装为 Windows 服务（生产推荐）

右键 `deploy\4_install_windows_service.bat` → **以管理员身份运行**

特点：
- 开机自动启动，无需登录
- 后台静默运行
- 服务管理：任务管理器 → 服务 → `TVManagementServer`

### 7. 开放防火墙端口

以管理员身份运行 PowerShell：
```powershell
netsh advfirewall firewall add rule name="TV管理系统" dir=in action=allow protocol=TCP localport=8080
```

### 8. 确认服务器IP

```
ipconfig
# 找 以太网适配器 → IPv4 地址，例如 192.168.1.100
```

**建议将服务器设置为固定IP**（避免重启后IP变化，所有客户端需要重新配置）

## 二、安卓TV 客户端部署

### 第一步：构建 APK

在**开发机**（你现在的电脑）执行：

双击 `deploy\5_build_android_apk.bat`

APK 文件输出到：
```
tvclient\app\build\outputs\apk\debug\app-debug.apk
```

### 第二步：安装 APK 到 TV

**方式A（ADB，需TV开启开发者模式）**

TV 设置 → 关于 → 多次点击"版本号" → 开启开发者模式 → 开启ADB调试

```bat
# 有线连接
adb connect TV的IP地址
adb install app-debug.apk

# 确认安装成功
adb shell pm list packages | findstr xny
```

**方式B（U盘，最简单）**

将 `app-debug.apk` 复制到U盘，插入TV，在TV文件管理器中找到并点击安装（需允许安装未知来源）。

**方式C（内网下载）**

将 APK 放到服务端静态目录：`tvservice\src\main\resources\static\downloads\`

TV 浏览器访问：`http://服务器IP:8080/downloads/app-debug.apk` 下载安装。

### 第三步：配置 TV 客户端

首次打开 App 会自动跳转到配置页面：

| 配置项 | 填写内容 | 示例 |
|--------|----------|------|
| 展示网址 | 要显示的看板URL | `http://192.168.1.100:8080` |
| 服务器WebSocket地址 | 服务端WS地址 | `ws://192.168.1.100:8080/ws` |
| 设备名称 | 这台TV的名字 | `车间一号屏` |
| 安装位置 | 可选描述 | `一楼大厅` |

配置完成后点击"保存并启动"。

**重新配置（以后需要修改）**：
- 遥控器按 `MENU` 键
- 或快速按 5 次 `返回` 键

## 三、PC小主机 客户端部署（接传统电视）

### 第一步：构建安装包

双击 `deploy\6_build_pc_kiosk.bat`

输出到 `xnykiosk\dist\`：
- `XNY Kiosk Setup 1.0.0.exe`（推荐，正常安装）
- `XNY Kiosk 1.0.0.exe`（便携版，免安装）

### 第二步：安装到PC小主机

将安装包复制到目标PC，双击安装（或直接运行便携版）。

### 第三步：配置PC客户端

安装后首次运行，右键屏幕选"⚙️ 打开配置"：

| 配置项 | 填写内容 | 示例 |
|--------|----------|------|
| 展示网址 | 看板URL | `http://192.168.1.100/dashboard` |
| 服务端WS地址（可选） | 服务端地址 | `ws://192.168.1.100:8080/ws` |
| 设备名称 | 这台PC的名字 | `办公室大屏` |
| 全屏显示 | 勾选 | ✓ |

点击"💾 保存配置"立即生效。

**快捷键**：
- `Ctrl+Shift+C` — 打开配置
- `Ctrl+Shift+Q` — 退出程序

## 四、管理系统使用

浏览器访问：`http://服务器IP:8080`

### 可对设备执行的操作

| 操作 | 说明 |
|------|------|
| 刷新页面 | 设备重新加载当前URL |
| 重载 | 强制清缓存重载（TV:重建WebView；PC:硬刷新） |
| ⚙️ 配置 | 修改URL、刷新间隔等，立即推送到设备 |
| 📷 截图 | 远程查看设备当前显示画面 |

## 五、常见问题

### Q: TV 连上服务端后显示"离线"
A: 检查 TV 和服务器是否在同一内网；服务器防火墙端口 8080 是否开放。

### Q: 截图功能无响应
A: 确认设备在线（绿色"在线"状态）；点击截图后等待 5-10 秒轮询。

### Q: TV 开机后 App 不自动启动
A: TV 设置 → 应用 → TV Client → 设为默认启动应用（不同品牌位置不同）。

### Q: PC Kiosk 程序被系统防病毒软件拦截
A: 在杀毒软件中将程序添加到白名单/信任列表。

### Q: 服务端重启后设备全部显示"离线"
A: 设备会在 1 分钟内自动重连，重连后自动变为"在线"。

## 六、目录结构说明（部署后）

```
C:\TVManagement\              ← 推荐的部署目录
├── tvservice-0.0.1-SNAPSHOT.jar
├── application-prod.yml      ← 生产配置（数据库等）
├── logs\
│   └── tvservice.log         ← 运行日志
└── start.bat                 ← 启动脚本
```

建议将 JAR 和配置文件复制到专用目录（如 `C:\TVManagement\`）再运行，不要直接在项目开发目录运行。
